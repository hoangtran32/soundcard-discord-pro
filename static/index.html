    Cấu Hình Discord Bot API

    Token này sẽ được dùng mặc định cho tất cả các phòng thoại không có token riêng.

    Hướng Dẫn Nhanh Tạo Bot Discord:

    1. Truy cập Discord Developer Portal.
    2. Tạo New Application → chọn mục Bot → nhấn Reset Token và copy Token.
    3. Bật các quyền Privileged Gateway Intents (Server Members Intent, Message Content Intent).
    4. Mục OAuth2 → URL Generator: tích chọn bot, các quyền Connect, Speak, Use Voice Activity và dùng link để mời bot vào server của bạn!

    Thêm Kênh Thoại Discord

    Nếu muốn phát đồng thời vào 2 kênh trong cùng 1 Server, cần 2 Token Bot khác nhau.
